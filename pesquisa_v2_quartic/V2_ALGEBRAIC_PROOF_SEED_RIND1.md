# V2 — Algebraic proof that the seed has relaxed linearity index one

Date: 2026-10-07

## Theorem

Let f:F_2^8 -> F_2 be the rotation-symmetric quartic seed whose SANF orbit representatives are

    (0,1),
    (0,1,2,3),
    (0,1,2,5),
    (0,1,3,5).

Then

    r-ind(f)=ind(f)=1.

The proof below does not enumerate the 32385 independent direction pairs.

## 1. Reduce to the quartic homogeneous part

Write

    f = q + Q,

where q is the quadratic orbit generated by (0,1), and Q is the sum of the three quartic RS orbits.

For directions a,b, the quadratic part of D_aD_b f comes entirely from Q, because D_aD_b q is constant.

If D_aD_b f is constant, then in particular the homogeneous quadratic part of D_aD_b Q must vanish.

## 2. Encode the two directions by Pluecker coordinates

For 0<=i<j<=7 define

    p_ij = a_i b_j + a_j b_i.

These are the coordinates of the decomposable bivector a wedge b.

For a squarefree quartic monomial x_i x_j x_k x_l, the quadratic part of its second derivative in directions a,b is

    p_ij x_k x_l + p_ik x_j x_l + p_il x_j x_k
  + p_jk x_i x_l + p_jl x_i x_k + p_kl x_i x_j.

Therefore the quadratic homogeneous part of D_aD_b Q is a linear map

    L : wedge^2(F_2^8) -> {quadratic squarefree forms in 8 variables}.

Both spaces have dimension 28.

For the present Q, direct row reduction of this 28 x 28 binary matrix gives

    rank(L)=22,
    dim ker(L)=6.

Choose free kernel coordinates

    u=p_37, v=p_46, w=p_47, x=p_56, y=p_57, z=p_67.

The complete kernel is then:

    p01=z
    p02=v
    p03=w
    p04=v+w+y+z
    p05=u+v+x+y
    p06=u+x
    p07=x

    p12=x
    p13=y
    p14=u+v+x+y
    p15=v+x
    p16=u+v+w+x
    p17=v+w+y

    p23=z
    p24=u+x
    p25=u+v+w+x
    p26=y+z
    p27=u+w+x+y

    p34=x
    p35=v+w+y
    p36=u+w+x+y
    p37=u

    p45=z
    p46=v
    p47=w

    p56=x
    p57=y
    p67=z.

Thus constancy of D_aD_b f forces the Pluecker vector p=(p_ij) into this six-dimensional kernel.

## 3. Impose decomposability

Because p_ij=a_i b_j+a_jb_i, the p_ij satisfy every Grassmann--Pluecker relation

    p_ij p_kl + p_ik p_jl + p_il p_jk = 0

for i<j<k<l.

After substituting the six-parameter kernel above, it is already enough to use only four such relations, corresponding to index quadruples

    0123, 0347, 0246, 0125.

Over F_2 they become

    R1 = v*y + w*x + z = 0,

    R2 = u*v + u*w + u*y + u*z + w + x = 0,

    R3 = u + v + v*y + v*z + w*y + w*z + x + y + z = 0,

    R4 = u*x + u*z + v + v*z + w*z + x + x*y + x*z = 0.

Here squares have been reduced using t^2=t for t in F_2.

Now work in the Boolean polynomial ring

    F_2[u,v,w,x,y,z] /
      <u^2+u, v^2+v, w^2+w, x^2+x, y^2+y, z^2+z>.

A Groebner-basis reduction of the ideal generated by R1,R2,R3,R4 and the six Boolean field equations gives exactly

    <u,v,w,x,y,z>.

Hence

    u=v=w=x=y=z=0.

Therefore every p_ij=0.

## 4. Conclude dependence of the directions

All 2 x 2 minors

    a_i b_j+a_j b_i

vanish. Thus the 2 x 8 matrix with rows a and b has rank at most one. Equivalently, a and b are linearly dependent over F_2.

We have proved:

    D_aD_b f constant  ==>  a,b linearly dependent.

Consequently no two-dimensional relaxed M-subspace exists, so

    r-ind(f)<=1.

Every nonzero one-dimensional subspace <a> is an M-subspace, since D_aD_a f=0. Hence

    ind(f)>=1.

Using ind(f)<=r-ind(f), we obtain

    ind(f)=r-ind(f)=1.

QED.

## Nature of the proof

The earlier exhaustive certificate checked all C(255,2)=32385 independent direction pairs.

This proof replaces that enumeration by:
1. one 28x28 binary linear map;
2. its rank-22 row reduction;
3. four Pluecker equations in six Boolean variables;
4. a six-variable Groebner certificate whose reduced basis is {u,v,w,x,y,z}.

The computation is therefore a compact symbolic certificate rather than exhaustive pair enumeration. The row reduction and Groebner reduction should be independently reproducible in SageMath/Singular/Magma before publication.

## Consequence for V2

The seed fact r-ind(f)=1 now has both:
- a brute-force exhaustive certificate; and
- a compact algebraic proof/certificate.

The general V2 theorems can cite the algebraic argument as the proof and retain the exhaustive script as independent verification.
