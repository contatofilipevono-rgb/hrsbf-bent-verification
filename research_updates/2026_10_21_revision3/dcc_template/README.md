# Springer layout draft — post-round-2 revision

Uses the official Springer Nature sn-jnl.cls and numerical style, as recorded in TEMPLATE_PROVENANCE.json. Sections and subsections use the class counters, labels and references; the bibliography uses bibitem/cite. Equations and theorem statements retain the article's checked display numbers. Statements and Declarations includes confirmed funding/interests, data availability and a visible author contribution/final approval marker. No contribution facts were invented.

Both PDFs were compiled with Tectonic (XeTeX-based), using the pdflatex class option. A separate pdfLaTeX build and the actual journal portal converter have not been tested. This is a review draft; it is not a submitted manuscript.
