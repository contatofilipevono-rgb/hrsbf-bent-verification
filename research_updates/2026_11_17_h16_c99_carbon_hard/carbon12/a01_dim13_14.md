### 1. Congruências Exatas de Poisson para $\dim W \in \{13, 14\}$ sob $W_f(u) = \pm 256$ [PROVADO]

Seja $f: \mathbb{F}_2^{16} \to \mathbb{F}_2$ uma função bent ($W_f(u) = 256(-1)^{\tilde{f}(u)}$ para todo $u \in \mathbb{F}_2^{16}$, com $\tilde{f}(u) \in \{0,1\}$), $W \le \mathbb{F}_2^{16}$ um subespaço linear de dimensão $d \in \{12, 13, 14\}$ ($\dim W^\perp = 16 - d \in \{4, 3, 2\}$), e $\ell_\alpha(x) := \langle \alpha, x \rangle$ ($\alpha \in \{0, \mathbf{1}_{16}\}$ correspondente a `use_chi` $\in \{0,1\}$, ou qualquer $\alpha \in \mathbb{F}_2^{16}$).

Pela fórmula de soma de Poisson em $\mathbb{F}_2^{16}$:
$$2^d - 2\,\operatorname{wt}\big((f \oplus \ell_\alpha)|_W\big) = \sum_{x \in W} (-1)^{f(x) \oplus \langle \alpha, x \rangle} = \frac{1}{2^{16-d}} \sum_{u \in \alpha + W^\perp} W_f(u) = 2^{d-8} \sum_{u \in \alpha + W^\perp} (-1)^{\tilde{f}(u)}.$$
Como $\sum_{u \in \alpha + W^\perp} (-1)^{\tilde{f}(u)} = 2^{16-d} - 2\,\operatorname{wt}\big(\tilde{f}|_{\alpha + W^\perp}\big)$, obtemos a **Identidade Exata de Peso Primal-Dual**:
$$\operatorname{wt}\big((f \oplus \ell_\alpha)|_W\big) = 2^{d-1} - 2^{d-8}\Big(2^{15-d} - \operatorname{wt}\big(\tilde{f}|_{\alpha + W^\perp}\big)\Big) = 2^{d-1} - 2^7 + 2^{d-8}\,\operatorname{wt}\big(\tilde{f}|_{\alpha + W^\perp}\big). \qquad (1)$$

Denote $r := \operatorname{wt}\big(\tilde{f}|_{\alpha + W^\perp}\big) \in \{0, 1, \dots, 2^{16-d}\}$. Avaliando $(1)$ para $d = 13$ e $d = 14$:

#### 1.1. Caso $\dim W = 13$ ($\dim W^\perp = 3$, $|W^\perp| = 8$, $r \in \{0,\dots,8\}$) [PROVADO]
Substituindo $d = 13$ em $(1)$:
$$\operatorname{wt}\big((f \oplus \ell_\alpha)|_W\big) = 4096 - 128 + 32 r = 3968 + 32 r, \qquad 3968 = 31 \times 128.$$
Portanto, para **qualquer** subespaço $W$ de dimensão $13$ e **qualquer** $\alpha$:
1. **Módulo 32 (Exato, sem incógnitas duais):**
   $$\operatorname{wt}\big((f \oplus \ell_\alpha)|_W\big) \equiv 0 \pmod{32}. \qquad (2\text{a})$$
2. **Módulo 64 e Módulo 128 (Acoplados a $\tilde{f}|_{\alpha+W^\perp}$):**
   $$\operatorname{wt}\big((f \oplus \ell_\alpha)|_W\big) \equiv 32\,(r \bmod 2) \pmod{64}, \qquad (2\text{b})$$
   $$\operatorname{wt}\big((f \oplus \ell_\alpha)|_W\big) \equiv 32\,(r - 4 \bmod 4) \pmod{128}. \qquad (2\text{c})$$
   **Quando $(2\text{b})$ e $(2\text{c})$ viram congruências fechadas (sem depender de $\tilde{f}$ desconhecida)?**
   * **Subcaso 13-Simétrico ($G_W \le C_{16}$ preserva $W$ e $\alpha$):**
     - Se $\rho^8(W) = W$ e $\rho^8(\alpha) \oplus \alpha \in W^\perp$: a involução $\rho^8$ age em $\alpha + W^\perp$. Se $\rho^8$ age **livremente** em $W^\perp \setminus (W^\perp)^{\rho^8}$ com subespaço fixo $(W^\perp)^{\rho^8}$, todo par não-fixo contribui $0 \pmod 2$ para $r$, logo $r \equiv \operatorname{wt}\big(\tilde{f}|_{(\alpha+W^\perp)^{\rho^8}}\big) \pmod 2$. Em particular, se $(\alpha + W^\perp)^{\rho^8} = \varnothing$ (por exemplo, $\alpha$ tal que $\rho^8(\alpha) \oplus \alpha \in W^\perp \setminus (1+\rho^8)(W^\perp)$!), então **$r$ é obrigatoriamente PAR**, forçando **$\operatorname{wt}((f \oplus \ell_\alpha)|_W) \equiv 0 \pmod{64}$**!
     - Se $\rho^4(W) = W$ e $W^\perp \cap U_4$: lembre que em $H(16,4)$ no ramo `c99 = 0` sob `B0_00`/`B0_11`, os sinais de $\tilde{f}$ em $U_4$ (`0x0000`, `0x1111`, `0x3333`, `0x5555`, `0x7777`, `0xffff`) são regidos pelas somas de cosets $H(v)$. Se $\alpha = 0$ e $W$ é **$\rho^4$-invariante** de dimensão $13$, então $\rho^4$ age em $W^\perp$ ($\dim 3$). Como $(\rho^4)^4 = \mathrm{id}$ em característica $2$, toda órbita de $\rho^4$ em $W^\perp$ tem tamanho $1, 2$ ou $4$:
       * Os pontos de órbita tamanho $1$ pertencem a **$U_4$**!
       * Se $W^\perp \le U_4$ (ex.: um hiperplano de dimensão $3$ dentro de $U_4$, logo $W \supset U_4^\perp$!), **todos os $8$ vetores de $W^\perp$ pertencem a $U_4$**, onde $W_f(u) = \pm 256$ já tem paridade/soma determinada! Aí $\operatorname{wt}(f|_W)$ é conhecido **exatamente em $\mathbb{Z}$** (a menos do sinal global $\sigma_0$)!
       * Se $\dim(W^\perp \cap U_4) = 1$ ($W^\perp = \langle u_0 \rangle \oplus P_2$ com $u_0 \in U_4 \setminus \{0\}$ e $\rho^4$ agindo com órbitas de tamanho $2$ ou $4$ fora), então $r = \tilde{f}(0) + \tilde{f}(u_0) + 2(\dots)$ ou $4(\dots)$, determinando $r \bmod 2$ (logo **$\bmod 64$**) e até $r \bmod 4$ (logo **$\bmod 128$**)!

#### 1.2. Caso $\dim W = 14$ ($\dim W^\perp = 2$, $|W^\perp| = 4$, $r \in \{0,1,2,3,4\}$) [PROVADO]
Substituindo $d = 14$ em $(1)$:
$$\operatorname{wt}\big((f \oplus \ell_\alpha)|_W\big) = 8192 - 128 + 64 r = 8064 + 64 r, \qquad 8064 = 63 \times 128 \equiv 0 \pmod{64},\ \equiv 64 \pmod{128}.$$
Portanto, para **qualquer** subespaço $W$ de dimensão $14$ e **qualquer** $\alpha$:
1. **Módulo 32 e Módulo 64 (Exatos para TODO $W$ de dim 14!):**
   $$\operatorname{wt}\big((f \oplus \ell_\alpha)|_W\big) \equiv 0 \pmod{32} \quad \text{e} \quad \operatorname{wt}\big((f \oplus \ell_\alpha)|_W\big) \equiv 0 \pmod{64}. \qquad (3\text{a})$$
2. **Módulo 128:**
   $$\operatorname{wt}\big((f \oplus \ell_\alpha)|_W\big) \equiv 64\,(r + 1 \bmod 2) \pmod{128}. \qquad (3\text{b})$$
   Logo, $\operatorname{wt}\big((f \oplus \ell_\alpha)|_W\big) \equiv 0 \pmod{128} \iff r = \operatorname{wt}(\tilde{f}|_{\alpha+W^\perp}) \equiv 1 \pmod 2$.
   * **Fechamento exato de $(3\text{b})$ sem incógnitas duais:**

     $$\operatorname{wt}(f|_{W_1}) + \operatorname{wt}(f|_{W_2}) \equiv 128 + 64(r_1 + r_2) \equiv 0 \pmod{128} \implies \left\lfloor \frac{\operatorname{wt}(f|_{W_1})}{64} \right\rfloor \oplus \left\lfloor \frac{\operatorname{wt}(f|_{W_2})}{64} \right\rfloor = 0 \pmod 2! \qquad (3\text{c})$$
     *(Note a beleza de $(3\text{c})$: cancelar $\tilde{f}(0) \oplus \tilde{f}(u_*)$ entre dois subespaços $W_1, W_2$ com mesmo $h_1 \oplus \rho^8(h_1) = h_2 \oplus \rho^8(h_2)$ elimina 100% qualquer dependência na função dual $\tilde{f}$ em **todo** $h \in \mathbb{F}_2^{16} \setminus D_8$, pois $u_*$ nem precisa pertencer a $U_4$: basta $h_1 \oplus \rho^8(h_1) = h_2 \oplus \rho^8(h_2)$, ou seja, $h_2 = h_1 \oplus s$ com $s = \rho^8(s) \in U_8$!!)*

Então $r(h) = \operatorname{wt}(\tilde{f}|_{W(h)^\perp}) \equiv \tilde{f}(0) \oplus \tilde{f}(h \oplus \rho^8(h)) \pmod 2$. Consequentemente, para **qualquer** $s \in U_8$ ($\rho^8(s) = s$, $256$ escolhas!) tal que $h \oplus s \notin U_8$, vale para toda função bent $C_{16}$-invariante:

### 2. Grau Máximo em $c$ (Teorema de Lucas + Valoração de McEliece + Pareamento) [PROVADO]

Para determinar o grau algébrico em $c = (c_1, \dots, c_n) \in \mathbb{F}_2^n$ de cada bit $B_k(c) := \left\lfloor \frac{S(c)}{2^k} \right\rfloor \bmod 2$ de uma soma inteira $S(c) = \sum_{p=1}^M g_p(c)$, onde cada $g_p(c) = O_p \oplus \bigoplus_{i=1}^n b_{i,p} c_i \in \{0,1\}$ é afim em $c$:

#### 2.1. Fórmula Exata de Lucas–Multinomial [PROVADO]
Sobre $\mathbb{Z}$, vale a identidade exata ponto a ponto para $O_p \in \{0,1\}$ e $L_p(c) = \bigoplus_{i=1}^n b_{i,p} c_i \in \{0,1\}$:
$$g_p(c) = O_p + (1 - 2 O_p)\, L_p(c), \qquad L_p(c) = \sum_{m=1}^n (-2)^{m-1} \sum_{i_1 < \dots < i_m} \Big(\prod_{t=1}^m b_{i_t, p}\Big) c_{i_1}\cdots c_{i_m}.$$
Somando sobre $p \in \{1, \dots, M\}$, defina para cada subconjunto não-vazio $I \subseteq \{1,\dots,n\}$ de cardinalidade $m = |I|$ a interseção assinada:
$$A_I := \sum_{p=1}^M (1 - 2 O_p) \prod_{i \in I} b_{i,p} = |B_I| - 2\,|B_I \cap O| \in \mathbb{Z}, \qquad B_I := \bigcap_{i \in I} \operatorname{supp}(b_i). \qquad (5)$$
Então a soma inteira exata $S(c) = \sum_{p=1}^M g_p(c)$ como polinômio pseudo-booleano multilinear em $\mathbb{Z}[c_1,\dots,c_n]/(c_i^2 - c_i)$ é:
$$S(c) = |O| + \sum_{m=1}^n (-2)^{m-1} \sum_{|I|=m} A_I \, c^I. \qquad (6)$$

Da equação $(6)$, a valoração 2-ádica do coeficiente inteiro de $c^I$ ($|I|=m$) é:
$$v_2\big(\operatorname{coef}_{\mathbb{Z}}(c^I)\big) = (m - 1) + v_2(A_I). \qquad (7)$$

Por outro lado, se na restrição de $f$ a um subespaço $W$ de dimensão $d$, todo gerador $f_i|_W$ tem grau em $x$ no máximo $4$, a identidade de soma em $\mathbb{F}_2^d$ ($\sum_{x \in W} x^U = 2^{d - |U|}$) implica que, na soma sobre **todo** $W$ ($M = 2^d$), a interseção não-assinada $|B_I| = \sum_{x \in W} \prod_{i \in I} f_i(x)$ satisfaz:
$$v_2(|B_I|_{\text{full } W}) \ge \max(0, \, d - 4m), \qquad v_2(|B_I \cap O|_{\text{full } W}) \ge \max(0, \, d - 4m - \deg(\chi \oplus f_0)). \qquad (8)$$
Combinando $(7)$ e $(8)$ na soma completa sobre $W$ (sem dividir por órbitas ainda), o termo de grau $m$ em $c$ em $\operatorname{wt}((f\oplus \ell_\alpha)|_W)$ tem valoração 2-ádica:
$$v_2\big(\operatorname{coef}_{\mathbb{Z}}(c^I \text{ em } \operatorname{wt}|_W)\big) \ge (m - 1) + \max(0, \, d - 4m) = \begin{cases} d - 1 - 3m, & \text{se } 4m \le d, \\ m - 1, & \text{se } 4m \ge d. \end{cases} \qquad (9)$$
*(Nota crítica: para calcular o grau Booleano exato de $\lfloor \operatorname{wt}/2^K \rfloor \bmod 2$, se $\operatorname{wt}(c) \equiv 0 \pmod{2^K}$ identicamente para todo $c \in \{0,1\}^n$ — pois toda sub-soma de $(6)$ já zera os bits $< 2^K$ — então $\frac{\operatorname{wt}(c)}{2^K} \bmod 2 \equiv \sum_{|I| \ge 1} \left(\frac{(-2)^{|I|-1} A_I}{2^K} \bmod 2\right) c^I$ quando todos os coeficientes individuais em $(6)$ são múltiplos de $2^K$! Se alguns coeficientes em $(6)$ tiverem $v_2 = K - s < K$ mas se cancelarem módulo $2^K$ apenas via $c_i^2 = c_i$, usa-se Lucas no quociente dividido pelo tamanho da órbita de simetria $g = |G_W| \in \{2, 4, 8\}$, o que é **estritamente mais fino**!)*

Vamos fazer a conta exata usando a decomposição de órbitas sob $\rho^8$ ($g=2$), $\rho^4$ ($g=4$) e $\rho^2$ ($g=8$):

#### 2.2. Decomposição sob $\rho^8$: $\operatorname{wt}(f|_W) = \operatorname{wt}_{\text{diag}}(c) + 2\,\operatorname{wt}_{\text{pair}}(c)$ [PROVADO]

  A condição necessária de bentness é exatamente **$S(c) \equiv T \pmod{2^t}$**, que equivale à conjunção dos $t$ bits binários $T = \sum_{r=0}^{t-1} T_r 2^r$ ($T_r \in \{0,1\}$)!

Usando a expansão inteira exata $(6)$, $S(c) = |O| + \sum_{m \ge 1} (-2)^{m-1} \sum_{|I|=m} A_I c^I$ com $A_I = |B_I| - 2|B_I \cap O|$:

#### 4.1. Extrator Geral de Nível $r \in \{0, 1, 2, 3\}$ (sem descartar níveis intermediários!) [PROVADO]
Em vez de exigir $S(c) \equiv 0 \pmod 4$ identicamente e abortar com `return -2` quando falha, extraímos **sequencialmente** as equações polinomiais exatas para cada bit $r = 0, 1, 2, 3$ até $t-1$ **desde que os níveis anteriores $0, \dots, r-1$ já sejam identicamente constantes $= T_0, \dots, T_{r-1}$ no espaço afim atual**:

1. **Nível $r = 0$ ($S(c) \equiv T_0 \pmod 2$, Grau $\le 1$):**
   $$P^{(0)}(c) := \big(|O| \oplus T_0\big) \oplus \bigoplus_{i=1}^n \big(|B_i| \bmod 2\big)\, c_i = 0. \qquad (22)$$
   * Se $P^{(0)}(c)$ não é o polinômio nulo: **NÃO descarte!** É uma **equação linear exata** em $c$ (ou $1=0$ se for a constante `{0}`)! Só passe para $r=1$ no mesmo $W$ se $P^{(0)} \equiv 0$ identicamente (isto é, $|O| \equiv T_0 \pmod 2$ e $|B_i| \equiv 0 \pmod 2$ para todo $i$).

2. **Nível $r = 1$ ($S(c) \equiv T_0 + 2 T_1 \pmod 4$, assumindo Nível $0$ identicamente nulo, Grau $\le 2$):**
   Como $|O| - T_0$ é par e todo $A_i = |B_i| - 2|B_i \cap O|$ é par:
   $$P^{(1)}(c) := \left(\frac{|O| - T_0}{2} + T_1 \bmod 2\right) \oplus \bigoplus_{i=1}^n \left(\frac{A_i}{2} \bmod 2\right) c_i \oplus \bigoplus_{i < j} \big(A_{ij} \bmod 2\big)\, c_i c_j = 0, \qquad (23)$$
   onde $A_{ij} \bmod 2 = |B_{ij}| \bmod 2$.
   * **Atenção:** Se $P^{(1)}(c) \not\equiv 0$ (exatamente o caso `rc == -2` ou `rc == -3` ou $B_0 = 4$ em `B0_11` que `SOLVE_C99_0_RANDW.py` descartava!!), **INSIRA $P^{(1)}(c) = 0$ NA MATRIZ MACAULAY COMO EQUAÇÃO DE GRAU $\le 2$!!** Só passe para $r=2$ se $P^{(1)} \equiv 0$ identicamente (isto é, $|O| \equiv T_0 + 2 T_1 \pmod 4$, $A_i \equiv 0 \pmod 4$, e $|B_{ij}| \equiv 0 \pmod 2$).

3. **Nível $r = 2$ ($S(c) \equiv T_{\le 2} \pmod 8$, assumindo Níveis $0,1$ identicamente nulos, Grau $\le 3$):**
   Aqui $T_{\le 1} = T_0 + 2 T_1$, $4 \mid (|O| - T_{\le 1})$, $4 \mid A_i$, e $2 \mid A_{ij}$ (note que $-\frac{2 A_{ij}}{4} = -\frac{A_{ij}}{2} \equiv \frac{|B_{ij}|}{2} + |B_{ij} \cap O| \pmod 2$):
   $$P^{(2)}(c) := \left(\frac{|O| - T_{\le 1}}{4} + T_2 \bmod 2\right) \oplus \bigoplus_{i=1}^n \left(\frac{A_i}{4} \bmod 2\right) c_i \oplus \bigoplus_{i < j} \left(\frac{|B_{ij}|}{2} + |B_{ij} \cap O| \bmod 2\right) c_i c_j \oplus \bigoplus_{i < j < k} \big(|B_{ijk}| \bmod 2\big)\, c_i c_j c_k = 0. \qquad (24)$$
   *(Cobre exatamente: $\dim 12 \bmod 16$ sob $\rho^8$ [$g=2, t=3$]; $\dim 13 \bmod 32$ sob $\rho^4$ [$g=4, t=3$]; e **$\dim 14 \bmod 64$ sob $\rho^2$ [$g=8, t=3$]**!)*

4. **Nível $r = 3$ ($S(c) \equiv T_{\le 3} \pmod{16}$, assumindo Níveis $0,1,2$ identicamente nulos, Grau $\le 4$):**
   Quando $P^{(0)} \equiv P^{(1)} \equiv P^{(2)} \equiv 0$ identicamente, temos $8 \mid (|O| - T_{\le 2})$, $8 \mid A_i$, $4 \mid A_{ij}$ e $2 \mid A_{ijk}$ (pois $|B_{ijk}|$ é par, logo $A_{ijk} = |B_{ijk}| - 2|B_{ijk} \cap O|$ é par!). Dividindo $(6)$ por $8$ módulo $2$:
   $$P^{(3)}(c) := \left(\frac{|O| - T_{\le 2}}{8} + T_3 \bmod 2\right) \oplus \bigoplus_{i=1}^n \left(\frac{A_i}{8} \bmod 2\right) c_i \oplus \bigoplus_{i < j} \left(\frac{-2 A_{ij}}{8} \bmod 2\right) c_i c_j \oplus \bigoplus_{i < j < k} \left(\frac{4 A_{ijk}}{8} \bmod 2\right) c_i c_j c_k \oplus \bigoplus_{i<j<k<l} \big(|B_{ijkl}| \bmod 2\big)\, c_i c_j c_k c_l = 0, \quad (25)$$
   onde os coeficientes exatos em $\mathbb{F}_2$ são:
   * Constante: $\left(\frac{|O| - (T_0 + 2 T_1 + 4 T_2)}{8} + T_3\right) \bmod 2$;
   * Linear ($c_i$): $\left(\frac{|B_i| - 2|B_i \cap O|}{8}\right) \bmod 2$;
   * Quadrático ($c_i c_j$): $\left(\frac{2|B_{ij} \cap O| - |B_{ij}|}{4}\right) \bmod 2$ (bem definido em $\mathbb{Z}$ pois $4 \mid A_{ij} = |B_{ij}| - 2|B_{ij} \cap O|$!);
   * Cúbico ($c_i c_j c_k$): $\left(\frac{|B_{ijk}|}{2} + |B_{ijk} \cap O|\right) \bmod 2$ (bem definido pois $2 \mid |B_{ijk}|$!);
   * Quártico ($c_i c_j c_k c_l$): $|B_{ijkl}| \bmod 2$.
   *(Cobre exatamente: **$\dim 13 \bmod 32$ sob $\rho^8$** [$g=2, t=4$]; **$\dim 14 \bmod 64$ sob $\rho^4$** [$g=4, t=4$]; e **$\dim 14 \bmod 128$ sob $\rho^2$** via Lema $(4)$ [$g=8, t=4$]!)*

### 5. Algoritmo Concreto de Extração (C + Python) com Queda Automática de Grau $4 \to 3$

Para explorar **tanto** os níveis nativos de grau $\le 3$ (Níveis $r=0,1,2$ em $\dim 12, 13, 14$ sob $\rho^8, \rho^4, \rho^2$, **sem descartar $r=1$ nem $B_0 \equiv 4$**, e usando **todos os caracteres $\alpha$ com $(1\oplus\gamma)\alpha \in W^\perp$ e cosets afins $y + W$ com $(1\oplus\gamma)y \in W$**) **quanto** o Nível $r=3$ ($\dim 13 \bmod 32$ sob $\rho^8$ e $\dim 14 \bmod 64$ sob $\rho^4$) **sem alocar $5{,}5$ milhões de colunas de grau 4**:

#### Como eliminar a parte de Grau 4 em $O(1)$ de RAM (Projeção de Schur em $R = 128$ Quádruplas Testemunhas):
Como provamos na Seção 3.5 (Eq. $20$), o vetor de todos os $\binom{109}{4}$ coeficientes de grau 4 $|B_{ijkl}(W)| \bmod 2$ gerado por subespaços $W$ de dimensão $13$ ou $14$ tem **posto linear minúsculo ($\le 50$)** sobre $\mathbb{F}_2$!
Portanto:
1. Sorteie fixamente $R = 256$ quádruplas $(i_q, j_q, k_q, l_q)$ ($q = 0, \dots, 255$) — apenas **$4$ palavras `uint64_t`** de assinatura de grau 4 (`sig4[4]`)!
2. Quando um subespaço $(y + W, \alpha)$ de dimensão $13$ ($\rho^8$-inv, $\bmod 32$) ou $14$ ($\rho^4$-inv, $\bmod 64$) atingir o Nível $r=3$:
   * Extraia em C os coeficientes de **grau $\le 3$** pela Eq. $(25)$ diretamente para `row_words` ($n_{\text{cols}} = 215.930$ colunas, já existente!) **E** calcule em microssegundos os $256$ bits `sig4[0..3]` nas quádruplas testemunhas (`popcount(B_i & B_j & B_k & B_l) & 1`).
   * Reduza `sig4[0..3]` contra uma mini-base Gaussiana de no máximo $256$ linhas (`piv4` de tamanho $256$, aplicando as mesmas operações de linha XOR nos `row_words` de grau $\le 3$!).
   * Se `sig4` reduzir a `0`: **VERIFIQUE DETERMINISTICAMENTE** em C se a combinação linear resultante dos indicadores de subespaços tem $|B_{ijkl}|_{\text{comb}} \equiv 0 \pmod 2$ em **todas** as quádruplas (ou numa segunda bateria independente de $2048$ quádruplas; para certificação formal Nullstellensatz, guarda-se a lista dos $\le 50$ subespaços combinados e verifica-se $\sum_s \operatorname{wt}_{\text{pair}}(f|_{W_s}) \equiv \dots \pmod{16}$!).
   * Insira a linha resultante (agora **100% de grau $\le 3$!**) na matriz Macaulay principal `gf2_echelon_insert`!

#### Código C Exato para Extração Multi-Nível ($r \in \{0,1,2,3\}$) + Eliminação Schur de Grau 4

```c
#include <stdint.h>
#include <string.h>

// Suporta ate MAX_PTS = 8192 orbitas (pares em dim 14 tem <= 8192 pares: 16384/2 = 8192 -> 128 uint64_t words!)
#define MAX_W 128

// Extrai o PRIMEIRO nivel nao-identicamente-nulo r in {0, 1, 2, 3} da congruencia S(c) == T (mod 2^t).
// Retorna:
//   r in {0, 1, 2}: row_words preenchido com polinomio EXATO de grau <= r+1 (sig4 = 0).
//   r == 3        : row_words preenchido com parte de grau <= 3 da Eq. (25), e sig4[0..3] preenchido
//                   nas 256 quadruplas testemunhas q4_idx[256 * 4].
//  -10            : S(c) == T (mod 2^t) ja vale identicamente até o nivel t-1 (nenhuma restricao nova).
int extract_multilevel_row(
    const uint64_t *basis_sub, // n * n_w words (ja empacotados nos M pontos da orbita de W \ D8)
    const uint64_t *O_word,    // n_w words (O ^ L_alpha empacotado nos M pontos)
    int n,
    int n_w,                   // ceil(M / 64), <= MAX_W
    int t_bits,                // t = K - v2(g): ex. 3 para (dim12,g=2,mod16) ou (dim14,g=8,mod64); 4 para (dim13,g=2,mod32) ou (dim14,g=4,mod64)
    int T_mod,                 // alvo T in [0 .. 2^t - 1] da Eq. (21)
    const int *col3_base,
    int off2, int off1, int off0,
    uint64_t *row_words,       // zerado pelo chamador
    const int *q4_tuples,      // 256 * 4 indices (i,j,k,l) para assinatura de grau 4
    uint64_t *sig4_out         // 4 uint64_t words (zerado pelo chamador)
) {
    int o_pop = 0;
    for (int w = 0; w < n_w; w++) o_pop += __builtin_popcountll(O_word[w]);

    int wi_pop[110], wo_pop[110], Ai[110];
    int lvl0_nz = ((o_pop ^ T_mod) & 1);
    for (int i = 0; i < n; i++) {
        const uint64_t *bi = basis_sub + (size_t)i * n_w;
        int wp = 0, wop = 0;
        for (int w = 0; w < n_w; w++) {
            wp  += __builtin_popcountll(bi[w]);
            wop += __builtin_popcountll(bi[w] & O_word[w]);
        }
        wi_pop[i] = wp;
        wo_pop[i] = wop;
        Ai[i] = wp - 2 * wop;
        if (wp & 1) lvl0_nz = 1;
    }

    // --- NIVEL r = 0 (mod 2, Grau <= 1): Eq. (22) ---
    if (lvl0_nz) {
        if ((o_pop ^ T_mod) & 1) row_words[off0 >> 6] ^= 1ULL << (off0 & 63);
        for (int i = 0; i < n; i++) {
            if (wi_pop[i] & 1) {
                int c = off1 + i;
                row_words[c >> 6] ^= 1ULL << (c & 63);
            }
        }
        return 0;
    }
    if (t_bits <= 1) return -10;

    // Checa se Nivel r = 1 (mod 4, Grau <= 2) eh nao-identicamente nulo: Eq. (23)
    int T0 = T_mod & 1;
    int T1 = (T_mod >> 1) & 1;
    int c0_r1 = (((o_pop - T0) >> 1) ^ T1) & 1;
    int lvl1_nz = c0_r1;
    for (int i = 0; i < n; i++) {
        if ((Ai[i] >> 1) & 1) lvl1_nz = 1;
    }
    // Precisamos tambem checar paridade de |B_ij|
    for (int i = 0; i < n && !lvl1_nz; i++) {
        const uint64_t *bi = basis_sub + (size_t)i * n_w;
        for (int j = i + 1; j < n; j++) {
            const uint64_t *bj = basis_sub + (size_t)j * n_w;
            int ip = 0;
            for (int w = 0; w < n_w; w++) ip += __builtin_popcountll(bi[w] & bj[w]);
            if (ip & 1) { lvl1_nz = 1; break; }
        }
    }
    if (lvl1_nz) {
        if (c0_r1) row_words[off0 >> 6] ^= 1ULL << (off0 & 63);
        for (int i = 0; i < n; i++) {
            if ((Ai[i] >> 1) & 1) {
                int c = off1 + i;
                row_words[c >> 6] ^= 1ULL << (c & 63);
            }
        }
        int c2_idx = 0;
        for (int i = 0; i < n; i++) {
            const uint64_t *bi = basis_sub + (size_t)i * n_w;
            for (int j = i + 1; j < n; j++) {
                const uint64_t *bj = basis_sub + (size_t)j * n_w;
                int ip = 0;
                for (int w = 0; w < n_w; w++) ip += __builtin_popcountll(bi[w] & bj[w]);
                if (ip & 1) {
                    int c = off2 + c2_idx;
                    row_words[c >> 6] ^= 1ULL << (c & 63);
                }
                c2_idx++;
            }
        }
        return 1;
    }
    if (t_bits <= 2) return -10;

    // --- NIVEL r = 2 (mod 8, Grau <= 3): Eq. (24) ---
    int T_le1 = T_mod & 3;
    int T2 = (T_mod >> 2) & 1;
    int c0_r2 = (((o_pop - T_le1) >> 2) ^ T2) & 1;
    int lvl2_nz = c0_r2;
    if (c0_r2) row_words[off0 >> 6] ^= 1ULL << (off0 & 63);
    for (int i = 0; i < n; i++) {
        if ((Ai[i] >> 2) & 1) {
            int c = off1 + i;
            row_words[c >> 6] ^= 1ULL << (c & 63);
            lvl2_nz = 1;
        }
    }
    int c2_idx = 0;
    uint64_t inter[MAX_W];
    for (int i = 0; i < n; i++) {
        const uint64_t *bi = basis_sub + (size_t)i * n_w;
        for (int j = i + 1; j < n; j++) {
            const uint64_t *bj = basis_sub + (size_t)j * n_w;
            int ip = 0, iop = 0;
            for (int w = 0; w < n_w; w++) {
                uint64_t iv = bi[w] & bj[w];
                inter[w] = iv;
                ip  += __builtin_popcountll(iv);
                iop += __builtin_popcountll(iv & O_word[w]);
            }
            if (((ip >> 1) + iop) & 1) {
                int c = off2 + c2_idx;
                row_words[c >> 6] ^= 1ULL << (c & 63);
                lvl2_nz = 1;
            }
            c2_idx++;
            int base3 = col3_base[i * n + j];
            for (int k = j + 1; k < n; k++) {
                const uint64_t *bk = basis_sub + (size_t)k * n_w;
                int p = 0;
                for (int w = 0; w < n_w; w++) p += __builtin_popcountll(inter[w] & bk[w]);
                if (p & 1) {
                    int c = base3 + (k - j - 1);
                    row_words[c >> 6] ^= 1ULL << (c & 63);
                    lvl2_nz = 1;
                }
            }
        }
    }
    if (lvl2_nz) return 2;
    if (t_bits <= 3) return -10;

    // --- NIVEL r = 3 (mod 16, Grau <= 4): Eq. (25) ---
    // Aqui r=0,1,2 deram identicamente ZERO! Logo row_words ainda esta TODO ZERADO!
    int T_le2 = T_mod & 7;
    int T3 = (T_mod >> 3) & 1;
    if ((((o_pop - T_le2) >> 3) ^ T3) & 1) {
        row_words[off0 >> 6] ^= 1ULL << (off0 & 63);
    }
    for (int i = 0; i < n; i++) {
        if ((Ai[i] >> 3) & 1) {
            int c = off1 + i;
            row_words[c >> 6] ^= 1ULL << (c & 63);
        }
    }
    c2_idx = 0;
    for (int i = 0; i < n; i++) {
        const uint64_t *bi = basis_sub + (size_t)i * n_w;
        for (int j = i + 1; j < n; j++) {
            const uint64_t *bj = basis_sub + (size_t)j * n_w;
            int ip = 0, iop = 0;
            for (int w = 0; w < n_w; w++) {
                uint64_t iv = bi[w] & bj[w];
                inter[w] = iv;
                ip  += __builtin_popcountll(iv);
                iop += __builtin_popcountll(iv & O_word[w]);
            }
            // Coef quadratico: ((2*iop - ip) / 4) & 1  (4 divide ip - 2*iop pois r=2 zerou!)
            if (((2 * iop - ip) >> 2) & 1) {
                int c = off2 + c2_idx;
                row_words[c >> 6] ^= 1ULL << (c & 63);
            }
            c2_idx++;
            int base3 = col3_base[i * n + j];
            for (int k = j + 1; k < n; k++) {
                const uint64_t *bk = basis_sub + (size_t)k * n_w;
                int p = 0, po = 0;
                for (int w = 0; w < n_w; w++) {
                    uint64_t ijk = inter[w] & bk[w];
                    p  += __builtin_popcountll(ijk);
                    po += __builtin_popcountll(ijk & O_word[w]);
                }
                // Coef cubico: (p/2 + po) & 1  (2 divide p pois r=2 zerou!)
                if (((p >> 1) + po) & 1) {
                    int c = base3 + (k - j - 1);
                    row_words[c >> 6] ^= 1ULL << (c & 63);
                }
            }
        }
    }
    // Assinatura de grau 4 nas 256 quadruplas testemunhas: |B_{ijkl}| mod 2
    for (int q = 0; q < 256; q++) {
        const uint64_t *b0 = basis_sub + (size_t)q4_tuples[4 * q + 0] * n_w;
        const uint64_t *b1 = basis_sub + (size_t)q4_tuples[4 * q + 1] * n_w;
        const uint64_t *b2 = basis_sub + (size_t)q4_tuples[4 * q + 2] * n_w;
        const uint64_t *b3 = basis_sub + (size_t)q4_tuples[4 * q + 3] * n_w;
        int p4 = 0;
        for (int w = 0; w < n_w; w++) {
            p4 += __builtin_popcountll(b0[w] & b1[w] & b2[w] & b3[w]);
        }
        if (p4 & 1) sig4_out[q >> 6] |= 1ULL << (q & 63);
    }
    return 3;
}
```
