## Limites obrigatórios

A documentação reporta compilação de teoremas sobre equivalência EA **de representantes canônicos**, índices relaxados e indecomponibilidade robusta a perturbações quadráticas sob hipóteses formais específicas. A classificação EA por isomorfismo de digrafos **não** se estende automaticamente a todos os pares com perturbações quadráticas arbitrárias. Também não se deve reivindicar bentness, APN, segurança criptográfica ou originalidade apenas pela formalização. A cópia no acervo não reexecuta Lean; os logs originais permanecem na branch fonte.
